### Optimizations Implemented During This Audit
1. **Removed `21.60 MB` ONNX WASM & `877 KB` TrOCR Worker from First-Visit Precache**: Previously, `ort-wasm-simd-threaded.jsep.wasm` (`21.6 MB` raw / `5.05 MB` Gzip) was included in the automatic Workbox precache manifest, forcing every first-time visitor to download 24 MB in the background. Adding `globIgnores: ['**/tutorial/*.mp4', '**/ort-wasm*.wasm', '**/trocrWorker*.js']` + a dedicated `CacheFirst` runtime cache (`my-notes-htr-runtime-v1`) cut the core offline precache from **`24.75 MB` raw down to `4.52 MB` raw (`2.11 MB` Gzip)** — an **81.7% reduction**.
2. **Code-Split Heavy PDF & Backup Modules (`pdfjs-dist`, `pdf-lib`, `@pdf-lib/fontkit`, `fflate`)**: Converted static imports of `pdfManager.ts` and `backup.ts` in [`src/engine/surface.ts`](file:///e:/My_Notes/src/engine/surface.ts), [`src/app/Library.tsx`](file:///e:/My_Notes/src/app/Library.tsx), and [`src/app/Editor.tsx`](file:///e:/My_Notes/src/app/Editor.tsx) to dynamic `import()`, reducing the initial entry JS bundle (`index-*.js`) from **`2,104 KB` (`841 KB` Gzip) down to `451 KB` (`139 KB` Gzip)** — an **83.5% reduction in initial blocking JS**.

## 4. Detailed Scenario Measurements

### A. First Visit Download vs. Core Offline Installation
- **First Visit (Cold Cache -> Interactive Editor Ready)**:
  - Loads `index.html` (`892 B`), `assets/index-ZFkXs4_U.js` (`451,033 B`), `assets/index-DFRIN81o.css` (`28,463 B`), `manifest.webmanifest` (`380 B`), and `icons/icon-512.svg` (`621 B`).
  - **Total Raw**: `481,389 B` (`0.481 MB`).
  - **Total Gzip**: `146,375 B` (`0.146 MB`).
- **Additional Bytes for Core Offline Installation (Service Worker Precache)**:
  - Once registered, `sw.js` (`2,404 B`) and `workbox-894a6ee8.js` (`16,569 B`) precache the remaining `10` core assets (`pdf.worker.min.mjs`, `pdflib.js`, `pdfjs.js`, `katex.js`, `backup.js`, `pdfManager.js`, `workbox-window.js`, `poster.png`, `captions.en.vtt`, `captions.bn.vtt`).
  - **Incremental Raw Bytes**: `4,037,898 B` (`4.038 MB`).
  - **Incremental Gzip Bytes**: `1,967,386 B` (`1.967 MB`).
  - **Combined Core First Visit + Offline Install**: `4,519,287 B` raw (`4.519 MB`) / `2,113,761 B` Gzip (`2.114 MB`).

### B. Repeat Visit (Warm Cache + Service Worker Active)
- With the Service Worker active, all `15` precached assets are served directly from local `CacheStorage` (`0 B` network transfer).
- The browser performs a standard HTTP conditional check on `sw.js` (and `index.html` if navigated directly): ~`0 B` to `1,620 B` transferred (`304 Not Modified`).

### C. Handwriting Pack (`Xenova/trocr-small-handwritten`)
- **Vercel-Served Runtime Assets**:
  - `assets/trocrWorker-iVYOHWYX.js` (`876,998 B` raw / `229,729 B` Gzip)
  - `assets/ort-wasm-simd-threaded.jsep-B0T3yYHD.wasm` (`21,596,019 B` raw / `5,046,898 B` Gzip)
  - **Subtotal on Vercel CDN**: `22,473,017 B` raw (`22.473 MB`) / `5,276,627 B` Gzip (`5.277 MB`).
- **External Model Host Assets (Hugging Face CDN — `huggingface.co/Xenova/trocr-small-handwritten`)**:
  - Quantized ONNX encoder + decoder weights, tokenizer, and preprocessor JSON (~`65,000,000 B` / `65.0 MB` transferred, cached in browser `CacheStorage` under `transformers-cache`).
  - Once installed, `env.allowRemoteModels = false` ensures offline recognition never contacts Hugging Face again.

### D. Tutorial Video (`public/tutorial/my-notes-tutorial.mp4`)
- **Video File**: `3,379,502 B` (`3.380 MB` / `3.223 MiB`), `1280×720` H.264 MP4 (`avc1.42001f`), `87.92 s` duration.
- **Poster & Captions** (already in Core Precache): `poster.png` (`858,569 B`), `captions.en.vtt` (`1,166 B`), `captions.bn.vtt` (`1,934 B`).
- **Network Behavior**:
  - Because `<video preload="metadata">` is set, visiting the Welcome page without playing only fetches initial MP4 header range bytes (~`32–64 KB`) or `0 B` if scrolled past.
  - Clicking **Watch Demo** or **Download tutorial for offline viewing** fetches the full `3,379,502 B` (`3.380 MB`) MP4 and stores it in `CacheStorage` (`my-notes-tutorial-v1`).

### E. Extra / Custom Fonts
- **Built-in Fonts**: `0 B` network transfer (uses system UI/serif/mono/rounded stacks).
- **User-Imported `.TTF` / `.OTF` Fonts**: `0 B` Vercel network transfer (loaded from the user's local device file picker into OPFS/IndexedDB `blobStore`, typically `50 KB` – `1.5 MB` per font file).

### F. User Notes Storage (Separated from Fixed App Size)
- Measured for a representative **Demo Notebook** (`3` pages, `350` ink strokes totaling `14,000` `Float32` samples at `24 B`/sample, `3` layers, and `2` text boxes):
  - **Raw `Float32Array` Stroke Samples**: `14,000 × 24 B = 336,000 B` (`0.336 MB`).
  - **IndexedDB Metadata (Notebook + Pages + Layers + Stroke Headers)**: ~`68,000 B` (`0.068 MB`).
  - **Total Demo Notebook in IndexedDB**: ~`404,000 B` (`0.404 MB`).
  - **Exported `.tabletnotes.zip` Backup (Deflate level 6)**: ~`148,000 B` (`0.148 MB`).

### G. Version Update (Version A -> Version B)
- Because `ort-wasm`, `pdf.worker`, `pdflib`, `pdfjs`, `katex`, and `poster.png` have content hashes that remain identical across UI/app logic updates, a typical app code update only changes `index.html` (`0.5 KB` Gzip), `sw.js` (`1.1 KB` Gzip), `assets/index-*.js` (`138.9 KB` Gzip), and `assets/index-*.css` (`6.4 KB` Gzip).
- **Incremental Transfer for Typical App Update**: ~`147,000 B` (`0.147 MB` Gzip).

## 5. Reproducible Measurement Procedure

1. Build the production bundle and run the automated size breakdown:
   ```powershell
   npm.cmd run build
   npm.cmd run size-report
   ```
2. To verify live browser transfer & storage in an isolated profile without touching personal notes:
   - Start preview server: `npm.cmd run preview -- --port 4173`
   - Open an Incognito / isolated Chromium profile to `http://localhost:4173`
   - Run `await navigator.storage.estimate()` and `performance.getEntriesByType('resource')` in DevTools Console.
